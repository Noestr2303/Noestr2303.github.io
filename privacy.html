Privacy policy

Last Second Save Analytics · Last updated: October 2026

What this tool is

Last Second Save Analytics is a private, personal tool. It is used only by the owner of the YouTube channel Last Second Save to analyse the performance of his own videos.

Data accessed

With the owner's consent, the tool requests read-only access (scopes youtube.readonly and yt-analytics.readonly) to:

  • the list, titles, publication dates and durations of the channel's own videos;
  • aggregated statistics for those videos (views, watch time, audience retention, likes, comments, shares, subscribers gained);
  • public comments posted on those videos.

The tool never modifies, uploads, deletes or publishes anything on YouTube.

How data is used and stored

The data is used only to produce a periodic performance report for the channel owner. Reports and notes are stored in the owner's own Google Sheet and sent to the owner's own email address. To write the report, the data is processed by an AI model (Anthropic's Claude API). Data is not sold, shared with advertisers, or used for any other purpose.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from the Google account security settings (Third-party apps with account access).
